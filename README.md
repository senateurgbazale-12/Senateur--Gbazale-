# Sénateur Gbazalé — plateforme musicale

## Ajouter les chansons
1. Mets tes fichiers MP3 dans le dossier `audio`.
2. Renomme-les exactement :
   - chanson-1.mp3
   - chanson-2.mp3
   - chanson-3.mp3
   - chanson-4.mp3
   - chanson-5.mp3
   - chanson-6.mp3
3. Ouvre `index.html` pour tester le site.

## Ajouter une photo
Le site utilise actuellement le logo `SG` comme emplacement. Une vraie photo pourra être ajoutée plus tard.

## GitHub
Le dossier contient uniquement des fichiers statiques : `index.html`, `style.css`, `audio/` et `images/`. Il peut être publié avec GitHub Pages.
